# Saus360 · versão web

Versão web do [Saus360](https://enriquewm.github.io/saus360web/): estoque, vendas, consignação, compras, financeiro e relatórios no navegador do celular ou do computador.

- **Abrir:** https://enriquewm.github.io/saus360web/
- **No iPhone:** abra o link no Safari → Compartilhar → **Adicionar à Tela de Início**.
- **No Android:** abra no Chrome → menu → **Instalar app** (ou Adicionar à tela inicial).
- **Sem conta:** toque em **Explorar a demonstração** para testar com dados de exemplo (ficam só no seu aparelho).
- Idiomas: português e espanhol (muda na tela de entrada e em Mais).

Os arquivos desta pasta são gerados a partir do repositório privado do app; não edite à mão.

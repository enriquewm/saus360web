# Saus360 · versão web

Página de apresentação e versão web do [Saus360](https://enriquewm.github.io/saus360web/): estoque, vendas, consignação, compras, financeiro e nota fiscal no navegador do celular ou do computador.

- **Apresentação:** https://enriquewm.github.io/saus360web/
- **Entrar no app:** https://enriquewm.github.io/saus360web/app/
- **Demonstração direta:** https://enriquewm.github.io/saus360web/app/#demo
- **No iPhone:** abra o app no Safari → Compartilhar → **Adicionar à Tela de Início**.
- **No Android:** abra o app no Chrome → menu → **Instalar app** (ou Adicionar à tela inicial).
- Idiomas: português e espanhol (a escolha na apresentação vale também para o app).

Os arquivos desta pasta são gerados a partir do repositório privado do app; não edite à mão.
